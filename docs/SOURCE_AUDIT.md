## Source hierarchy note

The protocol specification defines field semantics. The exact ArduPilot commit defines what this project’s firmware actually accepts. The official Guided page currently disagrees with commit `f808f78…` about body-rate support; the report therefore follows source behavior for implementation while preserving the discrepancy instead of silently choosing one account.
